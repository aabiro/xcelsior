## What is Xcelsior?

Xcelsior is a distributed GPU orchestration platform that aggregates consumer and data-center GPUs into a managed compute marketplace where independent hosts compete on price. Rent GPUs by the hour, on-demand or spot, or run serverless inference billed per token.

Every capability is reachable three ways: the REST API, a hosted MCP server, and an in-app AI assistant.

## Three ways to drive the platform

Everything the API can do, an agent can do. Pick the surface that fits where your
code already lives.

| Surface | Best for | Entry point |
|---------|----------|-------------|
| **REST API** | scripts, CI, your own backend | [`/openapi.json`](https://xcelsior.ca/openapi.json) |
| **Xcelsior MCP** | external agents, Claude, Cursor, ChatGPT, any MCP client | [`/mcp`](https://xcelsior.ca/mcp) |
| **Xcel AI** | in-app, nothing to install, chat in the dashboard | [`/dashboard/ai`](https://xcelsior.ca/dashboard/ai) |

MCP and Xcel AI expose comparable capability. Use MCP when the agent lives outside
Xcelsior; use Xcel AI when you want the same reach with no client, key, or config.
Both ask before any action that spends money.

New to the platform? The onboarding wizard sets up any of the three roles from your
terminal, and it finishes the job rather than printing instructions:

- **Rent** — picks a GPU off the live marketplace, sets up your SSH key, checks your
  wallet, and launches your first instance.
- **Provide** — detects your GPU, benchmarks it, prices it, registers the host, and
  installs the worker agent as a background service.
- **Integrate the SDK** — detects your framework, installs the client, writes real
  credentials to `.env.local`, verifies the connection, and hands you a working snippet.

Pick one, or run both sides of the marketplace at once. Requires Node.js 18+, nothing
to install:

```bash
npx @xcelsior-gpu/wizard@latest
```

## How It Works

1. **Providers** register GPU hosts via the worker agent. Hosts undergo automated admission gating (driver versions, security checks).
2. **Submitters** submit AI/ML jobs specifying VRAM requirements, priority, and isolation tier.
3. **The scheduler** matches jobs to admitted hosts on capacity, price, and host reputation.
4. **Billing** handles CAD-native pricing with 13-province GST/HST, wallet credits, and Stripe Connect payouts.

| Containers | Docker + gVisor/Kata sandboxing |
| Frontend | Next.js (App Router) |
| Billing | Stripe Connect, CAD-native |
| SDK | TypeScript client + public developer API |
