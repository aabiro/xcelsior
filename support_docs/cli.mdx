# Xcelsior CLI & Wizard

Whether you're looking to rent a GPU for your next AI project or you want to earn money by hosting your own idle GPU, the easiest way to get started is with the Xcelsior CLI Wizard.

## The Onboarding Wizard

The onboarding wizard is a highly automated interactive CLI that configures everything you need. It requires Node.js 18 or higher. You don't need to install anything permanently—just run it via `npx`:

```bash
npx @xcelsior-gpu/wizard@latest
```

The wizard will guide you through three different pathways based on what you want to achieve:

### 1. Rent a GPU (Submitter)
If you want to run a workload, the wizard will:
- Authenticate you with the Xcelsior platform.
- Check your wallet balance and prompt you to add funds if necessary.
- Allow you to pick a GPU from the live marketplace (e.g., RTX 4090, A100).
- Automatically configure your SSH keys.
- Launch your first instance and provide you with the direct SSH connection string.

### 2. Provide a GPU (Host)
If you have an idle GPU and want to earn CAD, the wizard will:
- Detect your NVIDIA GPU and verify your CUDA driver versions.
- Run an automated benchmark to classify your GPU's performance tier.
- Help you price your GPU per hour.
- Register your host with the central marketplace.
- Install the Xcelsior worker agent as a background systemd service so your GPU can accept jobs securely.

### 3. Integrate the SDK (Developer)
If you are building an application on top of Xcelsior, the wizard will:
- Detect if you are using a Python or TypeScript/Node framework.
- Install the appropriate SDK packages (`xcelsior` for Python, `@xcelsior-gpu/sdk` for TypeScript).
- Generate real, scoped API credentials and write them to your local `.env` or `.env.local` file.
- Verify the connection to the API and hand you a working code snippet to copy and paste.

## Scripting and automation

For automation beyond the wizard — CI/CD pipelines, scheduled retraining, programmatic instance management — use the TypeScript SDK. It talks to the same public REST API the dashboard uses, and handles authentication, retries, and typed errors for you.

```bash
npm install @xcelsior-gpu/sdk
```

```ts
import { XcelsiorApiClient } from "@xcelsior-gpu/sdk";

const client = new XcelsiorApiClient({ token: process.env.XCELSIOR_ACCESS_TOKEN });

const gpus = await client.gpu.listAvailable();
const quote = await client.billing.estimateCost();
const run = await client.instances.create({ name: "training-run" });
const logs = await client.instances.getLogs({ job_id: "JOB_ID" });
await client.instances.cancel({ job_id: "JOB_ID" });
```

The client is organised by resource — `instances`, `marketplace`, `billing`, `gpu`, `serverless`, `volumes`, `teams`, `sshKeys` — mirroring the REST API. Authenticate with an API credential from **Dashboard → Settings**. See the TypeScript SDK and API Overview pages for the full surface.

## Driving Xcelsior from an AI agent

If you would rather have an agent operate the platform than write client code, there are two routes:

- **Agent Skill** — one command teaches any agent to drive the REST API directly, with no MCP client required. See the MCP Server page.
- **Hosted MCP server** — connect Claude, Cursor, or any MCP-capable agent to `https://xcelsior.ca/mcp`.
