> **Correction, 7 November 2026.** An earlier version of this post said Slurm support was "available now for all Xcelsior accounts", with full Slurm compatibility, scheduler placement and live telemetry. That overstated it. The Slurm integration is restricted to Xcelsior operators and is not yet open to customers. This version describes what actually exists.

## What exists today

- **A Slurm adapter.** It writes a batch script from a job description, submits it with `sbatch`, follows the job through `squeue` and `sacct`, cancels it with `scancel`, and reads the job's output.
- **Cluster profiles.** Each profile describes one cluster: its partitions, its GPU model, how it expects GPUs to be requested, and its walltime limits.
- **Usage read from Slurm's own accounting.** The adapter reads start time, end time and elapsed seconds from the cluster's accounting database, not from a polling clock. Billing doesn't use these figures yet; when it does, a delay in checking a job won't be able to change its bill.
- **A lab validation.** On 7 November 2026 the adapter passed its full test suite on a two-node lab cluster: one GPU node and one CPU node.

## What it is not, yet

- **Not open to customer accounts.** The HPC dashboard and the Slurm API are restricted to Xcelsior operators.
- **No partner cluster is connected.** Jobs run only on Xcelsior's own lab cluster today.
- **No script upload.** The adapter takes a job description (command, GPUs, walltime) and writes the batch script itself. You can't paste an `sbatch` script.
- **No placement across clusters yet.** Xcelsior's scheduler does not route jobs into Slurm today.

## What comes next

1. A reconciler that keeps every job's state current without adding load to the cluster, so dashboards and agents read Xcelsior's copy instead of asking the cluster.
2. Submission that is safe to retry, and billing from Slurm accounting, first run in shadow mode next to the existing meters.
3. Partner Slurm clusters, once a partner route is live.

We'll update this post when Slurm jobs open to customers.
