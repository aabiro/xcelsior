MCP probes construct requests without the login cookie jar, so the browser
session cannot mask a bad bearer. They validate JSON-RPC results and handle JSON
and SSE responses. HTTP 200 with a JSON-RPC error, `isError`, an application error,
or an invalid `list_instances` result fails. The probe lists at most one instance
and does not modify compute resources.

The web session is revoked last so it can authenticate cleanup of every tracked
refresh credential, including the credential consumed during rotation. Cleanup
runs in `finally`; Ctrl+C and SIGTERM also reach it. Every logout is followed by
independent bearer and refresh rejection checks. A force kill or loss of network
can prevent cleanup; such a run must not be treated as evidence of revocation.

The final revision adds SIGTERM handling to the version used for the live run.
